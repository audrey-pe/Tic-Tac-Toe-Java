# Tic Tac Toe

## Présentation

**Tic Tac Toe** est un jeu de morpion développé entièrement en Java dans le cadre de ma formation à l’ENI École Informatique.

Le jeu permet à deux joueurs de s’affronter sur une grille de 3 × 3. Le premier joueur à aligner trois symboles identiques horizontalement, verticalement ou en diagonale remporte la partie. Si la grille est remplie sans alignement, la partie se termine par un match nul.

## Technologies utilisées

- **Java** : gestion de la logique du jeu, des tours des joueurs, des conditions de victoire et de fin de partie.

## Fonctionnalités

- Grille de jeu de 3 × 3.
- Alternance des tours entre les deux joueurs.
- Détection des combinaisons gagnantes.
- Gestion des matchs nuls.

## Installation

Cloner le dépôt Git :

```bash
git clone https://github.com/audrey-pe/Tic-Tac-Toe-Java.git
```

Ouvrir le projet dans un environnement de développement compatible avec Java, puis lancer la classe principale.
